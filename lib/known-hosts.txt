# Hostnames upstream's app source reaches for, as URLs. Every update scans the
# upstream checkout (before stripping) and fails if it finds a host not listed
# here: a new host can be a new phone-home that no strip rule or smoke test
# would notice. Tests, fixtures and docs aren't scanned.
#
# Being listed means looked at, not allowed. For a new host, find what talks
# to it (the failure names the file and line), then either add a strip rule
# or add it here with a note saying why it's fine.
#
# Baseline: v0.1.1-nightly.20261019.3360.
#
# Hosts are read the way a URL parser reads them (lowercase, punycode, without
# userinfo or a trailing dot), IP addresses included; for a host built at
# runtime (`${region}.example.org`), the domain written after the expression.
#
# Never listed here: reserved names that can't resolve (.invalid, .test,
# .localhost, .example) and loopback addresses. The scan skips them itself
# (lib/build.mjs isReservedHost). example.com, example.net and example.org are
# not among them: they're real domains that resolve, so each use is listed.
